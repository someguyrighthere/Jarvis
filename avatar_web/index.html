SARA / Dependencies & Forge

Core runtime, libraries, avatar and voice files are included in packaged SARA. Chrome, Ollama, SARA's AI model and coding tools are optional installation choices: skip them during setup and install them here later. Without Chrome voice recognition is unavailable; local AI needs Ollama and a model.

Each installation asks for confirmation and may download large files or require Windows approval. No application update is downloaded here.

For Forge's Python extras, set FORGE_PYTHON to the same environment shown by the checker. Optional WSL setup may require a restart and first-time Ubuntu initialization.

Select Refresh to check dependencies.
